# Archived upstream release notes: OpenCode 1.0.9

### CLI discovery and connection fixes

- Detect OpenCode CLI installations in common npm, Homebrew, and Linux package-manager locations.
- Improve CLI discovery in sandboxed IDE environments without relying only on `PATH`.
- Fix restoration of remote server connections and improve Windows startup reliability.
- Extend server startup and HTTP connection timeouts and continue reconnecting after transient failures.
