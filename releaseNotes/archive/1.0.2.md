# Archived upstream release notes: OpenCode 1.0.2

This release focused on diff review, terminal interaction, and Unicode filename handling.

### Improvements

- Show diffs independently for each turn and navigate to the next pending file after accepting or rejecting a change.
- Order diffs chronologically and simplify diff titles.
- Improve handling of non-ASCII filenames and malformed server data.
- Make terminal prompt insertion more reliable and avoid duplicate display of untracked files.
