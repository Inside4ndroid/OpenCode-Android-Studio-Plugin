# Archived upstream release notes: OpenCode IntelliJ Plugin 1.0.4

### Terminal links

- Recognize `@path#Lx-y` references in terminal output and open the referenced file and line range in the IDE.
- Restore the terminal input position when returning to the terminal tab.

### Diff and session improvements

- Capture local file baselines when an OpenCode turn starts and use Local History as a recovery source.
- Stage accepted AI changes and warn when local edits differ from the AI output.
- Improve Unicode paths, session recovery, prompt insertion, and Windows path handling.
- Add task-completion notifications and server password support.
