# Archived upstream release notes: OpenCode 1.0.9

### Diff reliability

- Fix missing diffs when a file is created and modified in consecutive turns.
- Improve detection of deleted and newly created files, including delayed server responses.
- Filter unchanged ghost diffs and protect user edits made between turns.
- Isolate per-turn session state to prevent stale events from affecting later diffs.
- Report a clear error when an occupied port does not host a healthy OpenCode server.
