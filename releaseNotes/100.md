## OpenCode ASP 1.0.0

Initial release of OpenCode ASP, the OpenCode Android Studio Plugin.

### Features

- Launch a local OpenCode terminal session or connect to an existing server.
- Detect OpenCode CLI v1 and v2 and use the compatible startup syntax.
- Authenticate with password-protected servers and optionally remember passwords securely.
- Send editor selections, files, and project context to OpenCode.
- Review AI-generated changes in the IDE diff viewer, then accept or reject them.
- Receive task-completion notifications and open terminal file links in the editor.
